# 陈乐天个人主页

这是个人主页的本地 HTML 版本。头像、样式与脚本均已嵌入 `index.html`，直接双击或在浏览器中打开即可完整预览。

## 内容维护映射

后续若用 Excel 维护内容，可按以下表头整理：

| Excel 分类 | 网页位置 | 关键字段 |
| --- | --- | --- |
| `profile` | 首屏与关于我 | `name_zh`, `name_en`, `tagline`, `email`, `phone`, `education` |
| `experience` | 专业经历 | `company`, `role_zh`, `role_en`, `period`, `summary_zh`, `summary_en`, `metrics` |
| `research` | 研究项目 | `title_zh`, `title_en`, `role`, `period`, `summary` |
| `leadership` | 校园经历 | `organization`, `role`, `period`, `summary` |
| `award` | 荣誉与能力 | `title`, `year`, `category` |

当前版本严格按作业要求，将全部个人信息直接写在 `index.html` 中；未连接外部数据库或在线服务。
